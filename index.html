Behind the visuals

The SQL that feeds the revenue report
SELECT  FORMAT(o.OrderDate, 'yyyy-MM') AS [Month],
        SUM(o.TotalDue)               AS Revenue,
        MAX(t.TargetAmount)           AS Target
FROM    Sales.Orders AS o
JOIN    Sales.MonthlyTargets AS t
        ON t.MonthStart = DATEFROMPARTS(YEAR(o.OrderDate), MONTH(o.OrderDate), 1)
WHERE   o.OrderDate >= DATEADD(MONTH, -12, GETDATE())
GROUP BY FORMAT(o.OrderDate, 'yyyy-MM')
ORDER BY [Month];
